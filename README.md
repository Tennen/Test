# 政治选择题 · 随身练习

手机端纯静态题库，包含 11 套资料、350 道完整选择题和 33 张对应原图。

- 逐题作答、答题卡、收藏、原图核对。
- 答错自动加入错题集；支持只做错题、逐题移出和清空错题集。
- 错题集仅存题目 ID 引用，移出时保留原始题目、答题记录和收藏。
- 再次答对不会自动移出，可在确认掌握后手动移出。
- 练习进度、收藏和错题 ID 存于当前浏览器 localStorage；错题复习进入时隐藏上次答案。

GitHub Pages 使用 `main` 分支的根目录发布。无需安装依赖或构建；入口为 `index.html`。

题目已逐项与照片标注核对；原资料中的缺页、略题、裁切残题和文字勘误可在“题库核对记录”查看。
