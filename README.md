# 政治选择题 · 随身练习

手机端纯静态题库，包含 11 套资料、350 道完整选择题和 33 张对应原图。

- 逐题作答、答题卡、收藏、原图核对。
- 答错自动加入错题集；支持只做错题、逐题移出和清空错题集。
- 错题集仅存题目 ID 引用，移出时保留原始题目、答题记录和收藏。
- 在错题练习中答对会自动移出普通错题集；答对显示绿色 2 秒后切换下一题。
- 练习进度、收藏和错题 ID、累计答错次数及高频错题 ID 存于当前浏览器 localStorage；错题复习进入时隐藏上次答案。

GitHub Pages 使用 `main` 分支的根目录发布。无需安装依赖或构建；入口为 `index.html`。

题目已逐项与照片标注核对；原资料中的缺页、略题、裁切残题和文字勘误可在“题库核对记录”查看。

累计答错超过 3 次（至少 4 次）的题目进入全局高频错题集合，可单独练习；答对、清空普通错题集或重置答题进度后，该集合和累计次数仍保留。次数从本功能上线开始累计，同一次作答重复点击仅计一次。
